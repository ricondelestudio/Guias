# 📚 Guías Escolares

Página para compartir las guías del colegio con los apoderados.

## Cómo subir una guía nueva

1. Entra a la carpeta **`guias`**, luego al **curso** y luego a la **asignatura**.
   Por ejemplo: `guias` → `3-basico` → `matematicas`
2. Arriba a la derecha: **Add file → Upload files**.
3. Arrastra el archivo (PDF, Word, foto…).
4. Abajo, clic en el botón verde **Commit changes**.
5. En 1 o 2 minutos la guía aparece en la página.

### Nombre recomendado para los archivos

Empieza el nombre con la fecha (año-mes-día) para que la página la muestre ordenada:

```
2026-11-18 Fracciones.pdf
```

En la página se verá como **"Fracciones · 18 de nov 2026"**.
Si el nombre no tiene fecha, la guía igual aparece, pero sin fecha y al final de la lista.

## Carpetas

| Carpeta | En la página |
|---|---|
| `1-basico`, `2-basico`, `3-basico`, `4-basico` | 1° a 4° Básico |
| `lenguaje`, `matematicas`, `ciencias`, `historia`, `ingles` | Lenguaje, Matemáticas, Ciencias, Historia, Inglés |

No cambies los nombres de las carpetas (la página los usa para ordenar).
El archivo `LEEME.txt` que hay en cada carpeta no se borra: sirve para que la carpeta exista.

## Otras carpetas (no tocar)

- `portadas`: fotos livianas de la primera página de cada guía, para que la página cargue rápido. Se crean con `herramientas/portadas.py`. Si subes una guía por la web y no tiene portada, la página la arma sola (solo es un poco más lenta).
- `iconos` y `manifest.webmanifest`: el ícono para agregar la página al celular como app.

## Para borrar o corregir una guía

Abre la guía en GitHub → menú **⋯** (arriba a la derecha) → **Delete file** → **Commit changes**.

⚠️ Todo lo que se sube aquí es público. No subir notas, RUT, fotos de niños ni datos personales.
